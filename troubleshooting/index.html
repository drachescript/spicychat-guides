Troubleshooting

Start with what the bot is doing, not the name of a feature. These links lead to existing guides with more complete instructions.

Start HereTest Your Bot
quick note: these are community guides. some fixes depend on the model or current editor, so start with the actual problem you are seeing.

not sure where to start?

pick the closest problem and try these few checks first. no need to rebuild the entire bot immediately xD.

the bot keeps speaking or acting for me
  1. check whether the Greeting writes {{user}}'s actions
  2. look for assumptions in the Scenario
  3. test a shorter correction in a fresh chat

more: stopping unwanted user control.

my Lorebook never seems to trigger
  1. is it attached and saved?
  2. did the exact keyword appear in the recent chat?
  3. try one unique test keyword

more: Lorebook troubleshooting.

my imported character is missing fields
  1. is the file a real character-card PNG or JSON, not just a picture?
  2. did Name, Greeting and Personality populate?
  3. fill advanced options, visibility and tags yourself

more: character imports.

my bot sounds repetitive or weird
  1. try a fresh chat
  2. look for repeating or contradictory instructions
  3. test one model setting at a time

more: repetition and model settings.

images don't look like the character
  1. are you making an Avatar or a Conversation Image?
  2. check the reference and character appearance details
  3. try a simpler scene and change one setting at a time

more: Avatars and Conversation Images.

my favorite bot disappeared
  1. find the bot ID in an old profile or chat link
  2. check both public and historical Archive records
  3. save accessible chat text before rebuilding

more: Archive for Dummies.
